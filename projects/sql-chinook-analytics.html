The scope

Nine queries against the Chinook sample database — a relational digital media store (customers, invoices, tracks, albums, artists, employees) — chosen to demonstrate the query patterns behind most real revenue, customer, and performance reporting: multi-table joins, subqueries, CTEs, and window functions.

This is a small, widely-used public practice dataset (59 customers, 412 invoices) — absolute revenue figures are illustrative, not business-scale. The point is the query technique.

All 9 queries

Sample query

WITH customer_spend AS (
  SELECT c.CustomerId, SUM(i.Total) AS total_spend
  FROM Customer c JOIN Invoice i ON i.CustomerId = c.CustomerId
  GROUP BY c.CustomerId
),
tiered AS (
  SELECT *, NTILE(4) OVER (ORDER BY total_spend DESC) AS spend_quartile
  FROM customer_spend
)
SELECT spend_quartile, COUNT(*) AS customers, ROUND(SUM(total_spend),2) AS segment_revenue
FROM tiered GROUP BY spend_quartile ORDER BY spend_quartile;
