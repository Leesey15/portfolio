Global Human Development Dashboard

Power BI · Data modeling & DAX · 193 countries, 2000-2015

Power BIDAXStar Schema Data Cleaning
In progress: the data model, all DAX measures, and the full page by page layout for this dashboard are built and documented below. The visuals themselves are being built directly in Power BI Desktop, and screenshots will be added here once complete.

In plain terms

Businesses use dashboards like this to track how outcomes relate to investment, whether that is regional performance against spending, or social impact against program budgets. This dashboard explores how health, education, and income relate to life expectancy across countries, and how that relationship has shifted between 2000 and 2015. It deliberately mirrors the three components of the UN Human Development Index (health, education, income), the kind of indicator work an organization like UNDP uses to track its own strategy and development outcomes.

Dataset

WHO Global Health Observatory life expectancy data across 193 countries, enriched with UN region and sub-region classifications. There are 18 indicators per country per year: life expectancy, adult and infant mortality, immunization rates, health expenditure, GDP per capita, population, schooling years, and income composition of resources (a scaled proxy for the income component of the HDI).

This is a real public health dataset with genuine gaps in several indicators, handled by leaving them as blanks rather than silently filling them in, so Power BI's aggregates exclude missing values correctly instead of treating them as zero.

Data model: star schema

Dim_Country  (193 rows)   CountryKey, Country, ISO3, Region, SubRegion, Status
Dim_Year     (16 rows)    YearKey, Year
Fact_HealthDevelopment (2,938 rows)  CountryKey, YearKey, + 18 indicators

Fact_HealthDevelopment[CountryKey] → Dim_Country[CountryKey]   (many-to-one)
Fact_HealthDevelopment[YearKey]    → Dim_Year[YearKey]          (many-to-one)

The same star schema modeling principle as the AfiLearn data warehouse project on this site, applied here in Power BI instead of SQL.

DAX measures

Avg Life Expectancy = AVERAGE ( Fact_HealthDevelopment[LifeExpectancy] )

Life Expectancy YoY Change =
VAR CurrentYear = MAX ( Dim_Year[Year] )
VAR PriorYearAvg =
    CALCULATE (
        [Avg Life Expectancy],
        FILTER ( ALL ( Dim_Year ), Dim_Year[Year] = CurrentYear - 1 )
    )
RETURN [Avg Life Expectancy] - PriorYearAvg

Life Expectancy Rank = RANKX ( ALL ( Dim_Country ), [Avg Life Expectancy], , DESC )

Full measure list (7 measures) in the repository README.

Planned layout: 3 report pages

  • Global Overview: KPI cards, a filled map colored by life expectancy, a developed versus developing trend line, and Year, Region, and Status slicers.
  • Human Development Lens: three KPI cards echoing the health, education, and income components of the HDI, plus a Gapminder style scatter plot (GDP per capita against life expectancy, sized by population, colored by region).
  • Regional Comparison: a bar chart and table comparing regions across all key indicators.

What this means for a business

Whether the numbers are countries or store locations, the underlying skill is the same: modeling data properly so it can be sliced by region, time, and category, then writing the calculations that turn raw figures into the metrics leadership actually asks for.
