Global Human Development Dashboard

Power BI · Data modeling & DAX · 193 countries, 2000-2015

Power BIDAXStar Schema Data Cleaning
In progress: the data model, all DAX measures, and the full page-by-page layout for this dashboard are built and documented below. The visuals themselves are being built directly in Power BI Desktop — screenshots will be added here once complete.

The question

How do health, education, and income relate to life expectancy across countries — and how has that relationship shifted between 2000 and 2015? This deliberately mirrors the three components of the UN Human Development Index (health, education, income), the kind of indicator work UNDP uses to track its own Digital Strategy and development outcomes.

Dataset

WHO Global Health Observatory life expectancy data across 193 countries, enriched with UN region/sub-region classifications. 18 indicators per country-year: life expectancy, adult/infant mortality, immunization rates, health expenditure, GDP per capita, population, schooling years, and income composition of resources (a 0-1 scaled proxy for HDI's income component).

This is a real public health dataset with genuine gaps in several indicators — handled by leaving them as blanks rather than silently filling them, so Power BI's aggregates exclude missing values correctly instead of treating them as zero.

Data model — star schema

Dim_Country  (193 rows)   CountryKey, Country, ISO3, Region, SubRegion, Status
Dim_Year     (16 rows)    YearKey, Year
Fact_HealthDevelopment (2,938 rows)  CountryKey, YearKey, + 18 indicators

Fact_HealthDevelopment[CountryKey] → Dim_Country[CountryKey]   (many-to-one)
Fact_HealthDevelopment[YearKey]    → Dim_Year[YearKey]          (many-to-one)

Same star-schema modeling principle as the AfiLearn data warehouse project on this site — applied here in Power BI instead of SQL.

DAX measures

Avg Life Expectancy = AVERAGE ( Fact_HealthDevelopment[LifeExpectancy] )

Life Expectancy YoY Change =
VAR CurrentYear = MAX ( Dim_Year[Year] )
VAR PriorYearAvg =
    CALCULATE (
        [Avg Life Expectancy],
        FILTER ( ALL ( Dim_Year ), Dim_Year[Year] = CurrentYear - 1 )
    )
RETURN [Avg Life Expectancy] - PriorYearAvg

Life Expectancy Rank = RANKX ( ALL ( Dim_Country ), [Avg Life Expectancy], , DESC )

Full measure list (7 measures) in the repository README.

Planned layout — 3 report pages

  • Global Overview — KPI cards, a filled map colored by life expectancy, a Developed-vs-Developing trend line, and Year/Region/Status slicers.
  • Human Development Lens — three KPI cards echoing HDI's health/education/income components, plus a Gapminder-style scatter (GDP per capita × life expectancy, sized by population, colored by region).
  • Regional Comparison — bar chart and table comparing regions across all key indicators.
